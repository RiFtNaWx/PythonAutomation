# Operator UI contract (ate/ui/web)

AI and humans must keep the console shape stable.

## Add a page

1. Add `<button class="tab" data-page="{name}">` inside the single `nav.tabs.glass`.
2. Add `<section id="page-{name}" class="page">` inside `main`.
3. Reuse `glass panel`, `db-grid`, `btn`, `btn accent`, `btn ghost`, `hint`, `row`.
4. Bump `styles.css?v=` cache query in `index.html`.
5. Wire clicks in `app.js` only (no second framework).
6. Setup Component/Part/Package/Operator/Version/Kind/Value/Scope use `.combo` (caret + body `#ate-combo-menu`). Do not bring back `<datalist>`.
7. Tags live on Setup More (not a Tags tab). **Board** is `#campaign-board` -- one fixture PCB per campaign, vocab from the same product class only, new names save to `#Test_Database/_ate/boards.yaml`. Free tags use `#db-tag-input` Space/Enter; chips compact with `+N more` and write `TAGS.txt` for File Explorer. `#label-scope` remembers free-tag history (this campaign / this class / all products). Board is never shared across OpAmp vs Logic.
8. Results `#run-ledger` lists session JSON from the central `#Test_Database`. Collapsed under `<details class="results-more">`. Last results + Export stay first. No extra tab.
9. Setup `#btn-open-central` opens the SharePoint-synced folder, or the `sharepoint.url` https if that folder is missing. It must not mkdir a private `#Test_Database`. `#btn-pick-cloud-db` (Choose folder) opens a Windows folder picker, writes `ate/config/cloud_db.txt`, and retargets the worker without restart. Shortcut paths differ per PC (Core AE vs AE FAE nested). Missing folder must not block START -- console still opens; `#notice-banner` tells the operator to Choose folder.
10. Setup `#pin1-hint` is the DUT orientation gate reminder (Abort if pin-1 is wrong).
11. Results `#btn-export-datalog` writes STS `sessions/datalog.md|.html|.pdf`. `#results-sts-status` shows Status / Total / Pass / Fail after START or DEMO (same Version folder). `#btn-fetch-datasheet` ingests the SKU PDF (local text, then one-SKU HTML if thin, OCR only if still thin) into `ate/config/limits/<part>.yaml` and probes `--xlsx` cells into `sheet_map` `paste.values`. `#btn-fill-excel` writes `paste.values`, probed `paste.narrative` (conditions/datasheet/conclusion), Excel comments, and photos onto `*_filled.xlsx` (SIM: `*_demo.xlsx`). The golden source xlsx is not overwritten. DEMO / Open SIM does not paste photos into the live lab xlsx. Get the Product Testing Report from a senior, or ask an AI agent to annotate paste cells from the OpAmp golden. STS PDF is the research log, not a second lab book. Agents read `AGENTS.md` / `CLAUDE.md` / `AI.md`; do not paste a Copilot block.
12. Results `#panel-progress-board` is the open lab board (everyone). Open by default. People table `#progress-board`: Who / Part / Opened (heartbeat campaign) / Last run / Runs / P/F / Idle / Seen. `#progress-owned` is tracking PIC + `owners.yaml` assigned. `#progress-unowned` is empty-PIC packages with Pick up (`board_claim` -> Version_1 + empty pic only, no steal). `#progress-who-tests` is who-has-what: Who / SKU / test id / source file:line / kind (catalog|golden|path-b). Register row (`#board-who` / `#board-part` / `#board-package` / `#board-class` / `#btn-board-register`) creates person + tracking SKU + folders. `#first-run-modal` Name is one `.combo` (`#first-run-who`): type the name then `+ Add <that name>` -- the typed text stays (do not wipe). Dropdown still lists `+ Add Your Name` when the box is empty; caret goes back to the list. Products are multi: owner filter `#first-run-filter-who` (Mine = `owners.yaml` `parts:` + tracking `pic:`, not empty provision folders), class/package filters (`#first-run-filter-class` / `#first-run-filter-pkg`), `#first-run-product` type-to-filter (RS622 lists every tracking package), `#first-run-product-chips` (x deselects), `#first-run-products` ticks (PIC label on each row), `#first-run-detect` (tracking vs disk, no scrape, no invented MSOP8). Continue with name only is enough (then Results Pick up). Ticked SKUs still call `provision_operator` `only_skus`. Kevin / All skip products. No extra tab. Setup `#part-scope` Mine/All filters the Part combo the same way. No Users table.
13. `#boot-splash` covers the app until worker ping + daily `sync_repo`. Not a tab.
14. Tests `#page-detect` (`data-page="detect"`) is Path A customize (this Version `test_catalog.yaml`) + version gaps + Path C AST scan/trigger. `#panel-campaign-tests` is the Add / save surface: tick registry ids, HTML5 drag `::` reorder on `#campaign-tests`, **Save this Version** writes `enabled_tests` list order (not A14 xyflow). `#panel-write-test` is Path B add body. Scan remembers the original file:line snippet pointer; Remember + enable triggers that snippet (does not rewrite the golden). Each person sees **their own code** first (`#detect-author` locked to this operator). `#detect-allow-others` must be ticked before other people's goldens can be listed, Remember'd, or Saved. `#btn-open-golden-bank` opens `goldens/` (`TUTORIAL.md` / `INDEX.md` / `GUIDE.md`). `#snippet-edit` Load/Save writes the original golden file (not a copy) and Save refreshes `goldens/INDEX.md`. VIH/VIL / `input_threshold` duplicates are hidden. `input()` / vendor imports stay blocked for wrap; SeeLim START uses Continue. Path B still lives in `ate/tests/`. Setup `#btn-edit-tests` opens `#tests-menu-modal` then that page. Search: `#test-list-search` (Setup Test program), `#campaign-test-search` (Path A), `#detect-search` (scan). `#detect-product` filters snippet rows by SKU in **this category**; `#detect-family` stays disabled. `list_detected_tests` returns `detected` (unmatched) and `located` (already registered); both paint in `#detected-tests`. Test program rows may show `src file:line` from `list_tests.source`. Detected / enable-test editors must not live on Setup or Run. Copy-from-part is parked. Same category only; do not merge another operator's catalog. Precise steps: `docs/VIBE_CODE.md`.
15. Setup person Save/Forget and product-code chips live on **Settings** (`#page-settings`), not daily Setup. **one Board** (`#campaign-board`), free tags, year, model, import xlsx, new product stay inside collapsed `<details class="setup-more">`. Save person calls `assign_owner_products` (matched codes -> `owners.yaml` `parts:` + this operator Version_1). Chip x unassigns yaml only (folders stay). Daily Setup is campaign Apply, Session, tick tests, START/DEMO.
16. Session hint shows VISA backend (`session_status.visa_backend`) on live Open Session. SIM also shows last AWG/PSU from `sim_bus`. Discover then Open Session share one USB scan. Empty Discover must show `#notice-banner` (not silent `{}`, not `window.alert`). Open Session failure after SIM must `refreshSession` so START is not left enabled. DEMO calls `bench_preflight`: USB *IDN -> START path, else SIM loopback then fake SCPI with `auto_continue` (no Continue). START never auto-continues. Leftover SIM + USB *IDN refuses START (Discover then Open Session). Open SIM tiles use `.tile.sim` (amber), not USB green. No USB: Open SIM. PSU output is never assumed ON until a test writes it. No `#btn-new-session`. START stamps campaign tags from `_manifest/tags.yaml`. `#walk-order` is channel-first or DUT-first, saved in `_manifest/run_prefs.yaml` with DUT count (`#dut-count`, 1-16) and probe ticks. There is no shared Run-conditions VCC bar. Each Test program row has a collapsed **Parameters** details (click to expand: sweep range, **VCC list**, **inputs n / levels**, **rails single|dual + PSU CH volts**, **settle_s / timeout_s / dwell_s**, **screenshot_from none|MSO|DMM** when the TestSpec needs that box -- DMM-only tests default DMM, never MSO; stale mso Write on IOZ/ICC falls through to DMM), stimulus AWG + freq/amp, imported `src file:line`, limits min/max) with **Write** to `_manifest/test_params.yaml`. Write RPC sends the Setup campaign (component/part/package/operator/version) so leftover worker context cannot steal the yaml. Fixture groups open so the editor is on Setup. `#run-dock` is sticky right-middle START; WAIT turns it into Continue; busy START is Continue/notice, not a silent no-op. START never calls `applyDb` (pins Setup campaign on the run RPC; that reload was Failed to fetch). `#run-need-hint` names the ticked TestSpec instruments (IOZ = PSU+DMM). Header tiles stay the Open Session map; unused tiles dim. START sends `test_params`; `RunParams.overlay_for` applies them per TestSpec (`vcc_list` wins over start/stop/step; `logic_inputs` scales 2^n **AWG input corners**, not extra MSO channels -- MSO stays CH1=stim CH2=Y). Delta Supply uses that test's VCC range and alternates AWG CH1 then CH2. DEMO/START `waitForRunComplete` must drop a stale poll if the worker restarted (`run_epoch` reset, not busy). CIN default 1/10/4 maps to 1, 5, 10 MHz. Empty test ticks keep `Select tests — standard defaults apply.` Test program rows show AWG shape from `list_tests.stimulus`. `#psu-wiring-hint` names CH1/CH2/CH3 volts and amps for the active family (OpAmp 2.5 V+2.5 V, not 5 V on CH1). Probe CHA/CHB defaults from family (OpAmp A+B, Logic/switch/level/power A); operator can tick B anytime. STS PDF prints the DUTs / channels / tests that actually ran.
17. Continue popup (`#modal`) is wait-only: worker does not start the next DUT/test until Continue or Abort. `#modal-later` (or click dim, or another tab) hides the popup without aborting (`gateHeld`). Header `#gate-dock-btn` Waiting + `#run-strip` stay as the notification; Open / `#run-details` reopens the checklist. `#run-continue` / `#run-strip-continue` / `#run-dock-go` Continue from the Run page, the strip, or the sticky right dock. Header + tabs stay clickable during a wait (z-index above the overlay). `#run-strip` shows WAIT / DELAY / RUN until the sequence finishes. DELAY is settle, not a dead START. Poll must not auto-reopen a held popup (`autoOpen: !gateHeld`).
18. Setup `#db-operator` lists only people who already have a folder on this Component/Part/Package. Kevin and ATE never appear. `#db-package` lists disk + tracking packages for this part (do not invent MSOP8). `#btn-plus-operator` / `#btn-plus-package` open `#campaign-plus-modal`: pick existing or type a new name, then Create folders (`ensure_product` this SKU, or `#add-operator-modal` / `provision_operator` for a brand-new person). Setup `#btn-add-operator` (and Apply on an unknown Operator folder) still opens `#add-operator-modal`. Default `#add-operator-all-skus` is OFF (this campaign tick only). Settings `#btn-provision-person` is the explicit All SKUs dump (`all_skus=True`). Create folders with ticks calls `provision_operator` `only_parts`. Tracking sheet only -- not a website search. Name lands in `#owner-select`. This browser's `ate_operator` is local preference: Add person / first-run Continue switches Setup to **that name + ticked products** (keep the current SKU if it is still ticked). Reload must not restore another person's worker `get_db_context`. Inventory `pic:` is the tracking-sheet owner, not this PC's folder. Shared `#Test_Database` is unchanged. Settings `#btn-provision-person` re-runs the all-SKU path for the current Operator folder. Probe `#channel-picks` are A/B/C... chips: tick for this run, `+` (`#btn-add-channel`) adds the next letter, `x` removes (keep at least one). `#walk-order` option text follows the ticked channels (not "A then B" when only A is on).
19. Settings `#page-settings` is this PC + person admin + Remove person + import family. Remove person requires typed `FORGET {label}` (not a login). Tick `#forget-wipe-folders` and type the folder name to delete that person's trees only. All/Kevin cannot be removed. `#page-users` stays parked.

20. Tests `#panel-ate-prompt` fills a Path A/B/C Cursor block for this campaign (Copy). `#panel-write-test` writes Path B `ate/tests/<family>/<id>.py` + `__init__.py` import (`save_path_b_test`). Refuses `input()`, vendor imports, and reserved ids. Setup Test program **Edit source** loads that file. Idle-restart worker after Save, then DEMO that id. Does not edit `runner.py`.
21. Recipe tab `#page-recipe` (`data-page="recipe"`) is A14: relationship panel (product/user grep) + xyflow island on `#recipe-root`. Canvas dist lives under `ate/ui/web/canvas/` (committed; zip users never run npm). Graph SoT is `ate/config/recipes/<id>.yaml`. Closed opcodes only (no eval). Path A `#campaign-tests` stays HTML5 reorder. Comparator class may appear on a recipe as `family: comparator` but `run_ic.yaml` stays `live: false` until a Path B suite exists.
22. Setup `#panel-logic-dc` is Path B Logic DC recipe (truth / isolation / pass_mode / `vcc_grid` FIXED POINTS + RANGE SWEEPS), collapsed behind `<details class="logic-dc-fold">` (not the Recipe tab). ICC VCC plan is `#logic-dc-icc-vcc-mode` named | 0.1 step | custom list (GT34 default step 2.0-5.5 from datasheet). `#logic-dc-pin-map` is pin/instrument/channel/role from `wire_map`. Not xyflow. Save product_model writes part yaml; Save Version overlay writes `_manifest/test_params.yaml`. ICC Connected: DMM series VCC, IO=0, CH2 OFF. PSU_MSO hides `#freq-label`.

## Forbidden

- Second `nav.tabs` (or a parallel top nav)
- Fourth webfont family (keep Barlow / JetBrains Mono / Space Grotesk)
- New design system / CSS reset
- Dumping large inline `style=` blocks for layout (small flex tweaks OK)
- Editing this tree from a regex "auto-improve UI" pass without running `python -m ate.core.check_ui_contract`

## Check

```
python -m ate.core.check_ui_contract
```

Fails if any `data-page` lacks `#page-*`, or if more than one `.tabs` nav, or if a fourth Google Fonts family appears.
