# DG822 Pro Error 116 was our own writes

Live CIN `session_2026-09-14_134320` got `CIN_pF ~ 0` and the AWG still showed Undefined Header 116.

Headers this file used to send that Pro does not have:

- `:OUTP3 OFF` / `:OUTP4 OFF` (`stop_output` / park) -- 2-channel box
- `:SOURn:FUNC:SQU:DCYC` (`setup_square`) -- DG4000
- `:SOUR1:FREQ` / `FREQ?` (CIN) and park `:FUNC SIN` + `:FREQ` -- every Continue

Golden that already worked on this bench: `:SOUR1:APPL:SQU freq,vpp,offset,0` then `:OUTP1 ON`. Change freq by OUTP OFF then APPL again.

`setup_square` now queries `SYST:ERR?` and prints if not 0.

Do not restart the worker while START is busy. Header STOP, then `restart_ate_worker.bat`.
