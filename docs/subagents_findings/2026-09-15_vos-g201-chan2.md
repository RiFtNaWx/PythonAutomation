# VOS G201 CHAN2 Path B

## Why wrap was wrong

`opa_tests.test_vos_sweep` records MSO **CHAN1** VAVG (the AWG DC). Fit slope~1 V/V, intercept 0, VOS~0 mV. That is VIN vs VIN, not G201 VOUT = G*(VIN+Vos).

Handover `docs/handover/VOS_RESEARCH.md`: closed-loop Vos = VOUT/Acl on the research G201 module. Fixture G201, not BUFFER/G11 AOL.

## Body

- `ate/tests/opa/vos.py` Path B. Does not import `opa_tests`.
- Dual PSU CH1/CH2 = |VCC|/2, AWG CH1 DC -5..+5 mV / 0.1 mV, MSO CHAN2 VAVG.
- Vos_mV = -intercept/slope * 1000 (Vin that nulls VOUT).
- SIM `_scope_item`: dual matched rails + AWG CH1 DC + CHAN2 (AWG CH2 off) -> 201*VIN. Vos_dut=0. Do not stamp datasheet typ 0.7 mV. G11 sine VPP stays Av=11 1-pole.
