## Rule

- product_model.oe or `oe_active` high|low -> enable ioz + limits IOZ_uA + recipe.ioz_when=oe_inactive
- oe none (G07/G08/G97/GT34/next-wave) -> ioz stays OFF
- RS2227 OE -> leakage_off (already stamps IOZ_uA). Do not enable logic_dc ioz
- LDO EN / RS29511 EN->READY -> not IOZ

## What changed

- `enabled_tests_for_part` unions ioz when `part_has_oe`
- Path B `_run_ioz` requires PSU+DMM only; OE via PSU CH3; AWG optional
- Dual-rail dispatch to `rs0204._run_ioz` (OE=GND)
- Checks scan every parts yaml (not hardcoded 125 only)

- Live G126 still needs DMM in series with Y and OE recable to PSU CH3
